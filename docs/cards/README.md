# Document Cards

One card per source actually read. A card is written **before** any claim is drawn from the document, and no claim status anywhere in this repository may rest on a document that has no card.

Governed by [`../04-methodology-symmetric-skepticism.md`](../04-methodology-symmetric-skepticism.md) and the reading rules in [`../../REPRODUCIBILITY.md`](../../REPRODUCIBILITY.md).

## Required sections

Every card carries these, in this order. A section with nothing in it says so explicitly; it is never omitted.

| § | Section | Purpose |
|---|---|---|
| 1 | **Provenance** | Institution, author, the three dates, type, oath status, URL, SHA-256, extent read, extraction method, OCR quality, image verification |
| 2 | **What the document asserts** | Atomic propositions, each with an exact quotation and page |
| 3 | **Declared source of each assertion** | What the document itself says its information rests on. Where it declares nothing, that is recorded as `no source declared` |
| 4 | **What the document does not say** | Propositions commonly attributed to this document that are absent from it. This section exists because most misuse of primary sources is by addition |
| 5 | **Temporal limits** | The period the document covers, the period it does not, and the gap between event and record |
| 6 | **Uncertainty language** | Every hedge, qualifier, caveat and confidence marker, quoted exactly. Removing a hedge is the commonest form of drift |
| 7 | **Redactions and missing parts** | What is withheld and whether the withholding can change the apparent meaning |
| 8 | **Possible conflicts with other documents** | Recorded as *potential*, resolved only in the evidence matrix after both sides have been read |
| 9 | **B2 binary determination** | Does this document cite or reference interrogation- or detention-derived reporting? Yes/No, with the exact passage. Every positive is hand-verified |
| 10 | **Evidentiary ceiling** | The strongest thing this document can support, and what it cannot support |

## Standing rules

1. **Quotations are verbatim**, with page. Source-language text is never silently normalised; OCR artefacts in a quoted passage are marked `[sic, OCR]` and the passage is checked against the page image first.
2. **A card records; it does not conclude.** Conclusions live in [`../evidence-matrix.md`](../evidence-matrix.md), which requires both sides of a question to have been read.
3. **Formatting is evidence.** Bold, italic, underlining and emphasis in the original are recorded, because characterisations of a document frequently rest on them.
4. **Absence is recorded as absence**, never as denial. "The document does not say X" is not "the document says not-X".
