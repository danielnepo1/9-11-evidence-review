# Pre-registration — B7: retrospective-only support census of the 9/11 Commission Report's endnotes

> **Written before `tools/note_dates.py` exists and before any per-note date extraction was run for analysis.** A feasibility count was taken in plan mode (93% of notes carry a parseable date; a *max-year* pass shows a strong raw signal) — that count used the **wrong metric** and is not a result. Everything below is fixed now so that nothing can be tuned to the outcome.

Pre-registered: **21 September 2026.**

---

## 1. The question

> For each endnote of the 9/11 Commission Report, what is the **earliest document date** it cites? A note supporting a claim about 1993–2001 events whose every cited document date is 2002 or later rests on **exclusively post-event evidence** — Commission interviews, interrogation reports, later analytic products — with no contemporaneous record cited.

This turns the project's three-dates rule (`04` §2.2: event date ≠ document date ≠ release date) from a reading habit into a corpus-scale measurement. It sidesteps the B1 classifier failure (D-001) entirely: it never asks what *kind* of source a citation is, only *when the cited document was produced*, and dates are structured tokens.

## 2. The metric — fixed

| Item | Rule |
|---|---|
| Unit | One endnote (segmentation validated: 1,657 notes, 13 chapters, zero gaps, `07` §4.1) |
| Measure | `min_doc_year` = the earliest **document** date cited in the note |
| **Wrong metric, excluded** | *Latest* cited year. A note citing a 2001 cable and a 2004 interview is contemporaneous-capable; max-year would misclassify it. The plan-mode feasibility count used max-year and is discarded |
| Classes | `contemporaneous-capable` (min_doc_year ≤ 2001) · `retrospective-only` (min_doc_year ≥ 2002) · `no-date` (no document date found) · `ibid-only` (note is only a back-reference) |
| Per-chapter output | counts of each class, and the retrospective-only share **computed over notes with a date**, with the no-date and ibid-only counts shown beside it, never hidden |

## 3. Citation-context rule — what counts as a document date

A date is a **document** date only when it terminates a citation: it follows a title in quotation marks, an author, an institution, or a document-type noun (report, memo, cable, interview, testimony, briefing, letter, email, transcript), and is separated from it by a comma or parenthesis. Examples that count: `CIA cable, "…," Jan. 4, 2000` · `George Tenet interview (Jan. 22, 2004)` · `DOJ Inspector General report, "…," July 2, 2004`.

A date does **not** count when it is inside a quoted title (`"Flight Path Study—… Flight 77," Feb. 19, 2002` → the document date is Feb. 19, 2002; a `2001` appearing inside the title is an event mention) or in narrative prose within the note (`On September 6, 1970, members of the Popular Front…`).

Known hazards, handled and counted: serial and page numbers that parse as years (a `2033` was seen); pre-1990 historical citations are legitimate and are **not** flagged; `ibid.` resolves to the preceding note's dates, or the note is classed `ibid-only` and excluded from the share.

## 4. The hand-check gate — fixed, and it comes first

**40 notes, drawn at random with a recorded seed, scored by reading each note** on one question: *is `min_doc_year` correctly identified?* AGREE / DISAGREE.

- **If disagreement ≤ 10%:** the per-chapter table may be written into `docs/09`, with the disagreement rate beside every number.
- **If disagreement > 10%:** the counts are **withheld**, the failure modes are characterised, and `docs/09` reports no numbers. This is the D-001 rule, applied before any number exists to be attached to.

No number from the extractor enters any document before the sample is scored. The sample file and its scores are committed.

## 5. Expectation — stated now so it cannot be retrofitted

**Chapters 5 and 7** — the plot-history chapters ("Al Qaeda Aims at the American Homeland"; "The Attack Looms") — are expected to show the **highest** retrospective-only share, because their subject matter is what the Commission could learn only from detainees and later reconstruction. Chapters describing US government activity (3, 4, 6, 8) are expected to show a **lower** share, because they cite contemporaneous memos, cables and PDBs.

**If the expectation fails, it is reported with the same prominence as if it held.** A result that chapters 5 and 7 are *not* retrospective-heavy would be a meaningful finding about the report's evidentiary base and would weaken a standard line of criticism of it.

## 6. Conclusion ceiling — fixed, not adjustable after

> A note whose cited basis is entirely post-event supports its claim with **retrospective evidence only**. It does **not** show the claim is false. It is **not** evidence for any alternative hypothesis. A chapter's retrospective-only share is a fact about the report's **evidentiary architecture**, not about what happened.

Under `08` §4, any document reporting these numbers discloses that this project runs a directed search and states that this measure was chosen because it tests the official account's evidentiary base — and that it would have been reported identically had it come out the other way.

## 7. What B7 does not do

It does not classify source types (that instrument failed and stays withdrawn). It does not weigh sources. It does not read the cited documents. It measures one dimension — when — over the whole apparatus, with its precision measured and published.
